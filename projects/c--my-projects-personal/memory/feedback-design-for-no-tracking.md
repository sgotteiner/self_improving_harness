He can't track all the moving parts of the setup and his life (2026-11-13: "if it doesn't pull automatically and doesn't ask me I won't remember to do it. The design needs to account for that"). Same day, when I made a memory to raise an open item at every session start: "you don't need to ping me, just have a list like my admin track list of next things, and every project should have a todo list."

**Why:** too much to track; anything that waits on his memory silently never happens - but being nagged isn't the answer either.
**How to apply:** a recurring task runs by itself (safe default, rollback, a switch). Everything else that's waiting becomes a line on the project's todo list (`tasks/todo.md` in the project; life admin = the Life Plan list), where he looks when he picks the next thing. Never "you can run X when you want", never a session-start nag. Related: [[feedback-token-efficiency]], [[user-life-routine]]
