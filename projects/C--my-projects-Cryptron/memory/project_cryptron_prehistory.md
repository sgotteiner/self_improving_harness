Before Cryptron, Sagi built a series of standalone attempts: a TradingView project, a
YouTube MCP, an eToro copy-trading tool, a find-reliable-Telegram-groups tool — and one
attempt at a complete system (TradingSetup), abandoned because it was coded before it was
designed (that lesson drove Cryptron's design-first rebuild, see [[cryptron-core-thesis]]).

**Why it matters:** the single tools weren't failures — they were organs without a body.
Cryptron is the body: TradingView → the TV hand (done), reliable-groups → calls/score
tools (done), YouTube MCP → the planned `sense_youtube` (already anticipated in the
schema comment), eToro copy-trading → a candidate future trading hand.

**How to apply:** when a new sense/hand is requested, check whether one of his old
projects already solved the hard part — port the organ, don't rebuild it. As of
2026-07-12 he feels things are finally moving forward: real experiments recorded and
infrastructure to improve, see [[raising-the-creature]].
