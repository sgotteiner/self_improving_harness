The user is the author and sole designer of **Cryptron**, a 24/7 self-improving crypto
research "creature." Its vision doc is `docs/cryptron_creature.md` — an explicitly loose
"ideas file," not a spec, that defines Cryptron as a living organism via a biological
metaphor (atom → molecule → tissue → organ → creature → words).

They think in this precise biological model and care a lot about getting the taxonomy
*conceptually* exact. They iterate on it out loud, refining definitions turn by turn, and
expect the doc to be kept in lockstep with the refined model. Frame work in terms of the
metaphor and reason about the concepts genuinely, not just surface text edits.

He invested 20+ hours in design before any code (his words, 2026-07-12); memory was the
hardest part to design — cracked when he saw it needed SQL + vectors + text graph
together. He considers Cryptron the most complicated engineering project he's done.
Design-first is now identity, not just method (contrast: TradingSetup, thrown away for
being coded first — see [[cryptron-prehistory]]).
